A configurable autosplitter for LiveSplit that has functionality for:
  - Splitting
  - Starting
  - Resetting
  - Displaying in-game information

The easiest way to use the autosplitter is by going to your Splits component in LiveSplit and putting the game name as Species Unknown. It will pop up saying there is an autosplitter available to use for the game.
